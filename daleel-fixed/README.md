# دليل (Daleel)

تطبيق قانوني شامل يغطي قوانين السعودية، مصر، الأردن، الإمارات، والكويت.

## المرحلة 1 - الميزات الحالية

- تسجيل الدخول وإنشاء حساب
- اختيار الدولة
- الصفحة الرئيسية
- البحث في القوانين
- المساعد القانوني بالذكاء الاصطناعي
- توليد العقود الأساسية
- رفع المستندات
- الملف الشخصي

## التشغيل

```bash
flutter pub get
flutter run
```
